모델과 대화 모드

이 대화에 저장되는 설정

Gemini로 생성하면 요청, 캐릭터·배경, 고정 기억, 추가 지시와 선택한 최근 대화가 Google로 전송됩니다. CSV 전체는 전송하지 않습니다. API 이용 요금과 데이터 이용 조건은 사용자의 Google 프로젝트에 따릅니다.

Gemini API 키 관리

저장 상태 확인 중…

암호화 저장을 끄면 앱을 종료할 때 키가 사라집니다. 키는 대화 파일이나 브라우저 저장소에 저장하지 않습니다. 같은 Windows 계정에서 실행되는 프로그램까지 차단하는 기능은 아닙니다.

모델 목록 조회에는 API 키만 사용하며 대화는 전송하지 않습니다.

컨텍스트와 생성 조절

입력 예산을 넘으면 오래된 대화부터 제외합니다. 고정 설정은 잘라내지 않습니다. 자동 요약은 하지 않으며 중요한 변경은 고정 기억에 직접 저장하세요. 캐릭터별 이름 설정과 CSV 검증은 모든 모드에서 유지합니다. Ollama 로컬 모델의 컨텍스트 크기는 입력 예산과 출력 한도의 합으로 설정되며 크기를 늘리면 메모리 사용량도 증가합니다. 추론 강도는 모델이 해당 값을 지원할 때만 적용합니다.

반복 입력은 Gemini 자동 캐싱의 대상이 될 수 있습니다. 실제 적중 토큰은 결과에 표시합니다. 적중·할인은 보장되지 않으며 수동 캐시 생성·보관은 이번 버전에 포함하지 않습니다.

생성 옵션

기본은 LLM 1회 호출입니다. 추가 교정을 꺼도 최종 태그의 CSV 대조는 수행합니다. 메모리 해제를 끄면 모델을 최대 5분 유지해 연속 호출 시 다시 로딩하지 않습니다.

처음 실행하거나 연결이 안 될 때

Ollama를 실행한 뒤 PowerShell에서 모델을 설치하세요. 최초 다운로드만 인터넷이 필요합니다.

ollama pull qwen3:8b

서버가 실행되지 않았다면 별도 터미널에서 ollama serve를 실행하세요. 설치 후 ‘연결 확인’을 누르세요.

태그 CSV는 저장소에 포함하지 않습니다. data/SOURCE.md의 형식에 맞는 파일을 준비하고 앱을 다시 실행하세요.

캐릭터와 배경

이 대화에 유지할 설정

캐릭터별 설정

구분용 이름은 요청에서 인물을 찾는 용도입니다. 출력에는 기본적으로 이름을 쓰지 않습니다. 학습된 이름·단부루 캐릭터 태그·LoRA 트리거를 쓸 때만 해당 인물의 ‘이름 그대로 사용’을 선택하세요.

고정 설정은 매번 포함합니다. 기본 모드는 최근 4회, 확장 모드는 모델 설정에서 선택한 범위의 대화를 입력 예산 안에서 이어갑니다. 오래 유지할 변경은 위 설정이나 고정 기억에 반영하세요. 설정은 생성·대화 전환 시 자동 저장됩니다.
